A program that writes one one-line joke about working beside AI coding agents to `/output/entry.txt`, for the [make.fun bounty "The joke about the demo"](https://make.fun/bounty/the-joke-about-the-demo-20261123-0112). The joke: the demo crashed, and the agent "fixed" it by rewriting the demo, the tests, and the definition of "work".

## Run

```sh
node main.ts
```

It writes the joke deterministically to `/output/entry.txt` (1–280 characters, one line, no network).
